# 023 — Export Trained Model to Ollama

Converts the Hugging Face checkpoint produced by `022-train-smollm` into a
**GGUF file** and imports it into Ollama so you can chat with it locally.

---

## Why GGUF?

| Hugging Face (PyTorch) | Ollama (GGUF) |
|---|---|
| Full float32 weights | Quantized (4-bit or 8-bit) |
| ~1.4 GB for 360M model | ~200 MB at Q4_K_M |
| Needs Python + transformers | Native binary, no Python |
| For training | For fast local inference |

---

## Prerequisites

```bash
# Ollama must be installed and running
ollama --version

# git and cmake must be available (for llama.cpp)
git --version
cmake --version
```

---

## Project structure

```
023-export-to-ollama/
│
├── convert.py              ← Main script (run this)
├── Modelfile.<name>        ← Generated by convert.py
├── <name>-f16.gguf         ← Generated GGUF (float16)
├── <name>-Q4_K_M.gguf      ← Generated GGUF (quantized, if --quantize)
└── llama.cpp/              ← Cloned automatically on first run
```

---

## How the pipeline works

```
HF checkpoint (PyTorch .bin / .safetensors)
        ↓
  convert_hf_to_gguf.py   (from llama.cpp)
        ↓
  model-f16.gguf           (float16, full precision)
        ↓   (optional --quantize)
  model-Q4_K_M.gguf        (4-bit quantized, ~4x smaller)
        ↓
  Modelfile                (tells Ollama how to load the model)
        ↓
  ollama create            (imports into Ollama)
        ↓
  ollama run               (chat!)
```

---

## Run — full pipeline

### Quickest way (float16, no quantization)

```bash
cd 023-export-to-ollama
python convert.py
```

This assumes the model is at `../022-train-smollm/google-ads-smollm`.

### With quantization (recommended — 4x smaller, faster)

```bash
python convert.py --quantize
```

### All options

```bash
python convert.py \
  --model ../022-train-smollm/google-ads-smollm \
  --name  google-ads-smollm \
  --quantize \
  --quant-type Q4_K_M \
  --system-prompt "You are an expert Google Ads assistant."
```

---

## Quantization types

| Type | Size (360M model) | Quality | Speed |
|---|---|---|---|
| `f16` | ~720 MB | Best | Slowest |
| `Q8_0` | ~380 MB | Near-lossless | Fast |
| `Q4_K_M` | ~220 MB | Good | Fastest |
| `Q5_K_M` | ~270 MB | Better than Q4 | Fast |

**Recommendation:** `Q4_K_M` for daily use, `Q8_0` if you notice quality loss.

## After import — use the model

```bash
# Chat interactively
ollama run google-ads-smollm

# Single prompt
ollama run google-ads-smollm "What is GAQL?"

# List all your Ollama models
ollama list
```

---

## What is a Modelfile?

The Modelfile tells Ollama three things:

```
FROM google-ads-smollm-Q4_K_M.gguf   ← which GGUF to load

SYSTEM """..."""                       ← system prompt (the model's persona)

PARAMETER temperature 0.7             ← how creative the responses are
PARAMETER num_ctx 2048                ← context window in tokens
```

You can edit the generated `Modelfile.<name>` and re-import:

```bash
ollama create google-ads-smollm -f Modelfile.google-ads-smollm
```
